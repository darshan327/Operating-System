  MEMORY MANAGEMENT

 1) Base and Limit Registers || Hardware Address Protection in Memory Management || Operating Systems

     Base and limit registers provide hardware-based memory protection. The base register stores the starting 
     physical address of a process, while the limit register defines the size of its allowed address space.
      For every memory access, hardware checks whether the logical address is within the limit. If valid,
       the physical address is calculated as Base + Logical Address. If invalid, a protection trap is generated
        and the operating system handles it. Only the OS can modify these registers.  

2) Address Binding in Operating Systems || Memory Management || Compile time || Load time || execution

     There are 3 main times:

       Compile Time
       Load Time
       Execution Time (Run Time)

         1️⃣ Compile-Time Binding

            Here, the exact memory location is known while compiling the program.

          2️⃣ Load-Time Binding

             Here, the compiler doesn't decide the final physical address.
             
             The program is created using relocatable addresses.
             
             When the program is loaded into RAM, the loader decides where it will be placed and adjusts the addresses.  


          3️⃣ Execution-Time Binding ⭐

               This is the most flexible.
               
               The address is translated while the program is actually running.
               
               The CPU generates a logical address:
               
               Logical address
                      ↓
                  MMU / Hardware
                      ↓
               Physical address
               
               For example:
               
               Base = 5000
               
               CPU generates:
               Logical address = 300
               
               Hardware translates:
               
               5000 + 300 = 5300
               
               So:
               
               Logical address → 300
               Physical address → 5300
               
               This translation happens during execution.   


3)  Q: What is the difference between logical and physical address?

       A good answer:
       
       A logical address is generated by the CPU and represents an address from the process's point of view.
       A physical address is the actual location in main memory (RAM). The MMU translates logical addresses
        into physical addresses before accessing memory. 


4) swapping in operating system | swapping in memory management

     Swapping is a memory-management technique in which a process is temporarily moved 
     from main memory (RAM) to backing storage to free RAM, and later brought back when
      it needs to execute. Moving RAM → disk is called swap out, and disk → RAM is called swap in.
      

5) Memory Allocation Techniques | Memory management Techniques | contiguous and non-contiguous


     1. Contiguous Memory Allocation

         Contiguous = together / next to each other.
         
         The entire process is placed in one continuous section of RAM.
         
         Real-life example 🏠
         
         Imagine you need 4 seats in a cinema.
         
         Contiguous allocation means:
         
         Seat 10
         Seat 11
         Seat 12
         Seat 13
         
         All seats are next to each other.


     2. Non-Contiguous Memory Allocation

         Here the process doesn't need to be in one continuous block.
         
         Its pieces can be placed in different parts of RAM.
         
         Real-life example 🪑
         
         You need 4 cinema seats.
         
         Non-contiguous allocation allows:
         
         Seat 10
         Seat 25
         Seat 40
         Seat 60
         
         They don't have to be next to each other.
         
         The OS keeps track of where each piece is.
